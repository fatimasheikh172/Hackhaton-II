# Midnight Dark Theme Spec
- **Base:** Tailwind Dark Mode (class-based)
- **Colors:**
  - Background: `bg-slate-950` (#020617)
  - Card/Sidebar: `bg-slate-900/50` with `backdrop-blur-xl`
  - Border: `border-slate-800`
  - Accent: `text-indigo-400`, `bg-indigo-600`
- **Effects:** - Hover: `hover:border-indigo-500/50`
  - Focus: `ring-2 ring-indigo-500`
